##  PopupMenuButton Widget

A material design widget in Flutter.


Displays a menu when pressed, usually with 3 vertical dots (overflow menu).


Commonly used for options or actions related to a UI element.


##  When to use it

Context menus


Overflow menus (in AppBar, ListTile, etc.)


Quick actions (edit, delete, share...)
